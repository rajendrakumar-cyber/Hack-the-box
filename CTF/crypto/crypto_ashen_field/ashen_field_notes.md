# The Ashen Field - Cryptography Writeup

This document outlines the step-by-step methodology and algebraic analysis used to solve the **The Ashen Field** challenge.

---

## 1. Vulnerability Analysis
The target implements a multivariate cryptosystem over $GF(2)$ with $N = 137$ variables:

* **Central Map**:
  The central map polynomial in the extension field $Q$ is defined as:
  $$E(F) = F^{2q} + F^q + 1 \pmod{g(t)}$$
  Since the base field is $K = GF(2)$ (so $q = 2$), we have:
  $$E(F) = F^4 + F^2 + 1$$
* **Frobenius Endomorphism & Linearization**:
  In a field of characteristic 2 ($GF(2)$), the squaring map is linear:
  $$(A + B)^2 = A^2 + B^2$$
  Furthermore, the variables are binary values ($x_j \in GF(2)$), which means they satisfy the field equation:
  $$x_j^2 = x_j \pmod 2$$
  $$x_j^4 = (x_j^2)^2 = x_j^2 = x_j \pmod 2$$

  Because squaring is linear and cross terms $2 x_j x_k$ vanish modulo 2, there are no cross-variable product terms (like $x_j x_k$) generated by the squaring operations $F^2$ and $F^4$.
  
  Consequently, all terms in the public key polynomials are either $x_j^4$, $x_j^2$, or $1$. Modulo $x_j^2 - x_j$, this simplifies to:
  $$x_j^4 \to x_j$$
  $$x_j^2 \to x_j$$

  This reduces the entire public key quadratic/higher-degree polynomial system into a strictly **linear system of equations** over $GF(2)$:
  $$\sum_{j=1}^N A_{ij} x_j = B_i \pmod 2 \quad \text{for } i = 1, \dots, N$$

---

## 2. Exploitation Methodology
We parse the polynomials from `output.txt` and construct the linear system matrix $A$ and vector $B$ over $GF(2)$:
* If variable $x_j$ appears an odd number of times (whether as $x_j^4$ or $x_j^2$) in $\text{poly}_i$, we set $A_{ij} = 1$; otherwise $A_{ij} = 0$.
* If the constant term `1` is present in $\text{poly}_i$, we set $B_i = C_i \oplus 1$; otherwise $B_i = C_i$ (where $C_i$ is the $i$-th bit of `encrypted_key`).

### Handling Singular Matrix (Free Variables)
Because the affine transformation matrices $S_A$ and $T_A$ were intentionally chosen to be singular:
* The rank of matrix $A$ is $135$ (meaning there are $2$ free variables).
* There are $2^2 = 4$ possible solutions.
* We perform Gaussian elimination, identify the free variables, branch on all 4 combinations, and perform back substitution to reconstruct candidate keys.
* For each candidate key, we attempt to decrypt the flag using AES-ECB.

## 3. Solver Code (`solve_ashen.py`)
```python
import re
import hashlib
from Crypto.Cipher import AES
from Crypto.Util.Padding import unpad

def find_all_solutions(A, B):
    n = len(A)
    pivot_cols, pivot_rows, row = [], [], 0
    for col in range(n):
        pivot = -1
        for r in range(row, n):
            if A[r][col] == 1:
                pivot = r
                break
        if pivot != -1:
            A[row], A[pivot] = A[pivot], A[row]
            B[row], B[pivot] = B[pivot], B[row]
            for r in range(row + 1, n):
                if A[r][col] == 1:
                    for c in range(col, n):
                        A[r][c] ^= A[row][c]
                    B[r] ^= B[row]
            pivot_cols.append(col)
            pivot_rows.append(row)
            row += 1
            
    free_cols = [c for c in range(n) if c not in pivot_cols]
    num_free = len(free_cols)
    
    solutions = []
    for mask in range(1 << num_free):
        X = [0] * n
        for idx, col in enumerate(free_cols):
            X[col] = (mask >> idx) & 1
            
        for r, col in reversed(list(zip(pivot_rows, pivot_cols))):
            val = B[r]
            for c in range(col + 1, n):
                val ^= A[r][c] * X[c]
            X[col] = val
        solutions.append(X)
    return solutions
```
